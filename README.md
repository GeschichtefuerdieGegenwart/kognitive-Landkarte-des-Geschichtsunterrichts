# Kognitive Landkarte des Geschichtsunterrichts

Interaktives Lernportal „Geschichte(n)“ für den Geschichtsunterricht am beruflichen Gymnasium (Eingangsklasse bis J2).

Live: https://geschichtefuerdiegegenwart.github.io/kognitive-Landkarte-des-Geschichtsunterrichts/

## Aufbau

1. **Wozu Geschichte?** – zehn Gründe (1.1–1.10)
2. **Was ist Geschichte?** – acht Prinzipien (2.1), Triftigkeiten (2.2), Formen (2.3), Sinnbildung und Urteil (2.4)
3. **Auswirkungen der Geschichte** – Gedächtnis, Public History, Geschichtspolitik, Erinnerungskultur, Agency, Medienkompetenz (3.1.1–3.1.6)
4. **Prüfen wie Profis** – Lateral Reading/SIFT, Prebunking, Bildprüfung, Fallstudien, Abschlussaufgabe

## Direktlinks

Jeder Abschnitt lässt sich direkt verlinken, zum Beispiel für QR-Codes auf Arbeitsblättern:

- `#m1` bis `#m4` öffnet einen Bereich
- `#s-2-2` öffnet Abschnitt 2.2, `#s-3-1-2` öffnet 3.1.2 usw. (Punkte werden zu Bindestrichen)

## Technik

Eine einzige Datei (`index.html`) ohne externe Bilder, Schriften oder Skripte. Alle Aufgaben funktionieren per Tippen, Maus und Tastatur. Die frühere Fassung liegt unter `archiv/fassung-2025.html`.
